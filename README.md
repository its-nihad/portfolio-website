# Portfolio Website

This is the personal portfolio of Mohamed Nihad, a B.Com graduate from Kerala, India, with a focus on finance and accounting and a growing interest in data analytics. It covers his education, work experience, skills and an academic project comparing the financial performance of Honasa Consumer and Hindustan Unilever.

The site is live at https://its-nihad.github.io/portfolio-website/ and is hosted on GitHub Pages.

It is built as a single `index.html` file using plain HTML, CSS and JavaScript, with no frameworks or external libraries. It works on phones and desktops and includes a mobile menu, a typing effect in the hero, animated skill bars and a contact form that opens the visitor's email app.

To run it locally, download or clone the repository and open `index.html` in any browser. To publish your own copy, push the file to a GitHub repository and turn on Pages in the repository settings.
